# Obsidian 网页剪藏与归档使用指南 (Web to Obsidian)

芥子书签内置了高效、安全的深度网页剪藏工作流，能够一键将网页长文、技术博客或新闻提取为符合 Obsidian 规范的结构化 Markdown 笔记，并直接写入本地 Obsidian 笔记库。

---

## 🌟 核心特性

1. **智能正文抽取与清洗**
   - 基于 Mozilla Readability 算法智能解析正文、标题、作者、发布时间、网站元数据。
   - 支持**区域选择器模式**：点击工具栏「选区」，高亮选择页面任意区域完成精准提取。
   - 自动过滤广告、导航栏、无关脚本和样式。

2. **Obsidian 规范 Markdown 转换**
   - 自动构建符合 YAML 标准的 Frontmatter 元数据（`title`, `source`, `author`, `clipped` 等）。
   - 保留标题层级、GFM 表格、任务清单、引用块与代码语言标识。
   - 实时提供**「源文本」**与**「渲染预览」**双视图。

3. **AI 结构化规范排版**
   - 点击「AI 规范排版」，调用「AI 设置」中配置的大模型服务对正文进行排版优化、语法整理和规范化（与书签 AI 功能共用同一出口，使用独立的排版提示词）。
   - 排版要求可在「AI 设置 → 提示词 → 剪藏排版」中自定义；占位符保护等安全规则固定生效，不受自定义内容影响。
   - **占位符安全保护机制**：排版过程中对代码块、图片 Token、公式进行自动锁定保护，防止大模型发生幻觉或意外篡改。

4. **防盗链图片转存图床**
   - 支持自动下载文章图片并转存至用户自定义图床，防止图源失效。
   - **本地 PicGo Server**：无缝对接本地 PicGo 客户端（默认端口 `http://127.0.0.1:36677/upload`）。
   - **Cloudflare R2**：基于 S3 协议直连用户自建的 R2 存储桶。

5. **本地 Obsidian Vault 静默直写**
   - 依托浏览器 **File System Access API**，笔记直接写入用户本地磁盘中的 Obsidian Vault 文件夹。
   - 无需本地搭建代理服务端，无需安装 Obsidian 社区插件。
   - 智能处理重名冲突（自动增加序列号）与合法文件名截断。

## 🚀 使用步骤

### 1. 初次绑定本地 Vault
1. 打开新标签页，进入「设置」→「Obsidian 剪藏」。
2. 在「本地 Obsidian Vault 授权」模块中点击**「选择本地 Vault 目录」**。
3. 在系统弹出的文件夹选择框中，选择你的 Obsidian 笔记库根目录（或库内子文件夹），点击「允许访问」。

### 2. （可选）配置文件转存图床
在「设置」→「Obsidian 剪藏」页面下方的「文章图片转存图床」中：
- 若使用 **PicGo**：确保 PicGo 正在运行并开启了内置 Server 服务。
- 若使用 **Cloudflare R2**：填写 Account ID、Bucket、API Token Key/Secret、公共访问域名与对象路径前缀，点击保存。已保存的密钥不会回显，更换时输入新值即可，留空表示保持不变。
- 填写有误时，保存会直接指出出错的字段。

### 2.1 （可选）开启 AI 自动排版
默认关闭。如需在每次提取文章后自动调用 AI 排版，在「设置」→「Obsidian 剪藏」的「AI 排版」中打开开关。开启后文章正文会发送到「AI 设置」中配置的模型，产生调用费用，并延长侧边栏的等待时间。

### 3. 开始剪藏
- **方式一（快捷弹窗）**：点击扩展栏图标打开 Popup，点击底部左侧的 **「剪藏到 Obsidian」** 按钮。
- **方式二（右键菜单）**：在任意网页空白处或选区右键，点击 **「剪藏当前网页至 Obsidian」**。
- **方式三（侧边栏）**：直接在浏览器右侧打开侧边栏（Side Panel）。

### 4. 预览、排版与保存
1. 侧边栏会自动提取当前网页正文并生成 Markdown。若上次有一篇其他网页的剪藏没有完成，侧边栏会提取当前网页，并在顶部提示「另有一篇未完成的剪藏」，可选择继续编辑或丢弃；上次未完成的正是当前网页时，则直接恢复。
2. 可随时修改笔记标题、调整 Vault 存放子目录（例如 `Clippings/Tech/`）。
3. （可选）点击 **「AI 规范排版」** 进行结构优化（未开启自动排版时，这是触发 AI 的唯一入口）。
4. 点击底部 **「上传图片并保存到 Obsidian」**，扩展将自动处理图床上传并生成 `.md` 文件写入本地 Vault。
5. （可选）点击 **「复制 MD」** 可直接将内容复制到剪贴板。

## 🛠️ 技术架构与安全性

- **零数据泄露**：模型请求直连大模型厂商，笔记写入完全在本地文件系统完成，不经过任何第三方中转服务。
- **任务状态机**：基于 IndexedDB（Dexie）管理剪藏任务流水，具备异常中断恢复与离线重试能力。
- **跨平台适配**：针对非 Chromium 内核环境自动提供安全的下载模式与导出兜底。
